# 从零重建：模型合同与验收门槛

状态：最小基线已实现；数值与工程验证见 [核验结果](VALIDATION.md)，未建立未来收益预测模型。确认流程：系统生成候选 → 用户确认长期权重 → 月度跟踪固定目标。此文从目标与约束出发，不将现有实现视为正确性标准。

## 0. 什么可以证明

可证明的是：在明确输入和约束下，求解结果满足资金守恒、交易限制及数学最优性误差界。历史统计量不是未来分布真值；不能证明某组合未来实现某收益/回撤。所谓严格模型必须同时列明其不能证明的部分。

## 1. 候选生成的最小基线

输入为同一时间截点以前、已完成月份、已核验的总收益序列。每只资产的月收益 r[t,i] 按自身总收益指数计算。

零基线统计量：mu[i] = mean(r[:,i])，S = sum((r[t]-mu)(r[t]-mu)^T)/(T-1)。mu是样本均值，不叫未来收益预测；不向其他类别平均值平移。样本不足2个完整收益观测不生成协方差。

用户此前明确保留的生产风险估计为 C = 0.8S + 0.2diag(S)。它作为显式经验选项与S零基线对照，不宣称20%是数学最优，也不自动切换LW。移除35%均值收缩及其隐含的横截面收益先验。

对每个研究收益水平a求解：

    minimize    w^T C w
    subject to  sum(w)=1, w>=0, mu^T w>=a

这是半正定C下的凸二次问题。20个点只是图形采样密度，不是投资参数。最低方差到最大历史均值之间生成可行研究候选；点序号不代表固定风险偏好。没有用户确认的类别、集中度限制，不擅自加50%或20%上限；必须显示集中度，不能声称模型自动覆盖信用、流动性或机构分散。

不通过回测Sharpe最大、50%权重稳定性等任意门槛认定长期最优目标。最低样本方差点仅作明确标识的研究参考，所有新目标都须确认，已保存目标不自动替换。

## 2. 数值证明义务

标准化目标和收益约束、解析梯度，先验证可行性，再求解。求解器success不是充分证据。

对可行w，另解线性规划 s = argmin grad(f(w))^T x（相同可行域）。凸性给出：

    0 <= f(w)-f(w*) <= grad(f(w))^T(w-s)

检查此全局一阶差距上界、约束残差和矩阵半正定；数值容差标记为数值容差。金额精度由币种/交易规则决定，不用统计参数替代。失败点不得标成最优；可行备用必须单列状态。

验证：闭式两资产解、已知对角协方差解、尺度不变性、资产排列不变性、RiskFree零风险、单资产、常量/重复列、等收益、最高收益端点、缺失数据和伪成功结果拒绝。

## 3. 月度执行模型

月度层只接收已确认w，不重新估计mu或择时。新增/授权资金优先；必要时建议卖出，现金底线修复和显式退出单列。Cash不产生收益、不是RiskFree；待到账款不能支付当前买入。

变量为每期各资产买入毛支出b、卖出金额s、持仓h、独立现金c、待到账款p。已知费率f/g时：

    h'[i] = h[i] + b[i]/(1+f[i]) - s[i]
    F = sum(b[i]*f[i]/(1+f[i]) + s[i]*g[i])
    c' = c + 新增资金 + 已到账净款 - sum(b) - 其他已确认现金支出
    p' = p + 本期未到账卖出净款 - 本期到账净款

实际到账日、买入上限、可赎回金额、起购额/金额步长、用户授权现金和现金底线是输入约束，不使用未来资金或整月假设额度。

配置跟踪：在明确的可投资资本口径A下，先最小化 sum(abs(h'[i]-w[i]*(A-F)))；再在第一目标最优集合内最小化卖出额；如仍有多解，再最小化买入额。不用“卖出 + 0.0001×买入”混合不同优先级。L1跟踪是明确选择的偏差度量，不是唯一正确的用户效用。

连续规划仅作为可验算的基线。实际金额步长、买卖互斥、结算时序必须再验证；不能将取整后的结果宣称为连续或整数全局最优。尚未建模的规则必须标记，不以经验常数悄悄替代。

## 5. 切换门槛

1. 理论：目标、变量、约束、统计假设逐项写明，经验项登记。
2. 数值：独立解/最优性界、资金守恒和约束残差通过。
3. 历史：同一输入与简单基线、窗口/扰动对照，报告不利案例，不能把历史选择冒充独立预测验证。
4. 产品：原入口；确认前目标不变；无交易可行时明确资金暂存；数据不足不伪造最优。
5. 限制：完整会计引擎与实际渠道限制仍逐项验收，不宣称一次重写已经覆盖所有风险。
