# Ledoit–Wolf 是否替换固定 20%：扩展离线实验

研究日期：2026-09-19。生产基线：`5b26353`。**结论：本轮不建议统一替换，继续保留固定 20% 对角收缩。** 这不表示 20% 已被证明最优，而是当前 Ledoit–Wolf 实现尚无足够稳定的收益、风险和执行优势支持迁移。本轮只增加离线研究材料，未修改生产算法、保存的目标或页面入口。

## 2. 主要结果与解释

36个月训练、最小方差、成交费率15bp的结果：

- 国际7组中，LW的Sharpe均略低于固定20%，差值约−0.001至−0.034；波动和回撤互有胜负。不能将多数很小且区间跨零的差值解释为固定20%有显著、普遍优势。
- 国内全池：Sharpe **1.728 → 1.844**，年化波动 **3.79% → 4.00%**，月度最大回撤 **2.88% → 2.69%**。
- 国内去重复份额池：Sharpe **1.748 → 1.806**，年化波动 **3.80% → 4.19%**，回撤 **3.00% → 3.47%**。收益风险指标并非一起改善。
- 国内债券、股票、海外/黄金三个分组：Sharpe均略降。窗口变化也会改变结论，例如去重池24月窗口LW的Sharpe差为−0.038，36月为+0.058，60月为+0.139。
- 国内全池Sharpe差的95%条件区间约 **[−0.095, +0.374]**，去重池约 **[−0.192, +0.360]**，均跨零。波动差区间则分别约 **[+0.055, +0.361]个百分点**、**[+0.200, +0.606]个百分点**。这是当前轨迹的条件不确定性，不包含重新选基金、参数搜索和数据修订的不确定性，也未经多重比较校正。

因此，截图中的改善可以是真实的该样本历史现象，但不能外推成所有资产集合的稳定改善。详细窗口、执行账户和机制结果见汇总表，所有分期/成本/滞后结果见CSV。

实际执行共完成 **640个账户（320组配对）**。固定目标、正常新增的40组配对中，LW末值相对差异范围为 **−8.12%至+8.81%**；国内全池为+4.24%，去重池+5.42%，但各只有一个满足长度要求的入场队列。国际多个家族随入场时间正负翻转。因此，国内改善值得记录，但不足以支撑对所有用户资产集合统一替换。限购、零新增和双倍费用的完整结果也已保留。

## 3. 为什么自动收缩没有必然更好

本项目固定20%使用 `0.8 S + 0.2 diag(S)`，保留每个资产的样本方差，缩小相关项；当前LW使用 `(1−α) S + α μI`，其中μ为平均方差。因此，这次比较同时改变了**收缩强度和收缩目标**。[scikit-learn官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.LedoitWolf.html)

我们增加同一分母下的对角20%与等方差20%控制组。对角20%的分母变化没有改变最小方差权重；换成等方差目标则会改变配置。国内全池固定等方差20%的Sharpe为1.812、波动4.15%，已呈现与LW相似的部分变化。不能把全部收益差归功于自动选择α。

已知协方差实验中，LW在同方差和高维样本的平均真风险较小；但异方差股债场景较差。该场景的低波动资产与高波动资产被推向共同方差，会影响最小方差配置。这是机制解释及模拟证据，不是对所有股债组合的定理。矩阵估计误差更小也不保证投资收益更高。

## 4. 独立工程核验发现：先修诊断求解精度

LW协方差实现与独立安装的sklearn 1.8.0，在常规、异方差、单资产、常量、高维输入上吻合，最大矩阵误差约1.11e−16。

但现有诊断 `_minimum_variance_weights` 的默认求解停止精度受协方差量纲影响。同一组模拟收益改以百分数表示，理论最优权重不应变化，原函数却明显变化。模拟复现中原十进制输入结果的目标方差为经过严格求解验证结果的约13.24倍。**此数字只描述该数值复现，不能解释为用户组合风险高13倍。** 证据见 `results/implementation_checks.json`。

本研究统一标准化目标函数、提供解析梯度、严格检查收敛与约束残差，以免把求解误差误认作估计器优势。闭式两资产解与尺度不变性回归测试通过。现有截图的诊断结果应在修复这个问题后重算；不能直接沿用其数字决定是否迁移。

建议下一步仅做有针对性的诊断求解修复及单位不变性回归，不重构入口、不变更默认协方差估计、更不自动覆盖用户确认的长期目标。若以后继续研究，应把“对角目标下的自适应收缩”单独立项，用新的预留验证数据判断，而不是在本次结果上继续挑参数。

## 5. 数据和统计边界

- 国际数据来自[French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)，是研究组合而非中国可购买基金。国际收益按美元计算，国内按人民币计算，只在同一组内配对比较，没有混合币种计算家庭收益。
- 下载文件属于当前历史修订版本（文件说明包含202607版本）；美国数据库自2025年起有CIZ口径变化。虽然逐期训练没有使用未来收益，但本实验不是逐历史时点数据版本回放，不能排除修订影响。
- 国内是当前存续、人工预设的扩展池，存在幸存者及选样偏差。基金总收益经过项目口径核验，尚未用第二家独立净值源逐日交叉核对。两组重复份额另做去重敏感性，不算独立证据。
- 月度回撤低估日内/日度路径风险。Sharpe采用零基准用于配对比较，不是扣除同期无风险收益的超额Sharpe。
- 账户实验是统一初始持仓的代理账户，不是用户真实历史账户；费率与限购是场景假设，不是历史渠道实录。基金总收益再投资代理不模拟每次现金分红登记、税费或外汇交易。
- 120月训练在部分国内组不足24个月样本外，不生成结果；不足60个月的短样本保留但不作为长期证据。国内子组相互重叠，美国/北美及多种股票组合也高度相关，不计算独立“胜率”。
- 自助法重采样已实现的配对收益，没有每次重新拟合投资策略；区间是描述性、条件性的，不能作为已证明未来优越的依据。
