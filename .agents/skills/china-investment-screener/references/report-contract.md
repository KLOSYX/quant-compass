# 输入输出契约

## 建议输入

```json
{
  "objective": "三年内稳健增值",
  "horizon_years": 3,
  "initial_amount": 50000,
  "monthly_amount": 3000,
  "max_drawdown": 0.08,
  "liquidity_days": 30,
  "target_return": 0.04,
  "target_return_is_hard": false,
  "allowed_types": ["债券型", "指数型-债券", "货币型"],
  "excluded_types": [],
  "channels": ["ant", "broker"],
  "as_of_date": "2026-07-12"
}
```

## 报告结构

1. **结论摘要**：目标能否由可验证候选池合理支持，最重要的限制是什么。
2. **目标与假设**：列出用户输入、代理采用的默认值和仍待确认项。
3. **覆盖说明**：候选池总数、成功、失败、过滤、最终数量及数据日期。
4. **优先候选**：3 至 8 个，同类分组展示。
5. **淘汰和观察项**：记录关键淘汰原因，避免选择过程不可审计。
6. **渠道状态**：分别说明公开开放、蚂蚁已确认、证券账户通常可交易和待确认。
7. **风险与局限**：历史数据、来源、分类、费率、流动性和未来不确定性。
8. **执行前检查**：在购买页面确认费率、限购、最低持有期和最新公告。

## 候选表必备字段

| 字段 | 说明 |
|---|---|
| 代码与名称 | 标识产品及份额类别 |
| 产品类型 | 用于同类比较 |
| 渠道状态 | public_open / ant_verified / broker_exchange / unknown |
| 数据截止日 | 防止把旧数据当实时数据 |
| 年化收益 | 指定区间和净值口径 |
| 最大回撤 | 指定区间 |
| 年化波动 | 指定频率 |
| 正收益月份占比 | 稳定性参考 |
| 费用与限制 | 无法获取时写未知 |
| 适合原因 | 与用户目标对应 |
| 不适用情景 | 明确边界 |
| 置信度 | 高/中/低及原因 |

目标收益若与风险预算不匹配，应指出冲突并给出情景选择，不为满足目标而强行推荐高风险产品。
